# C Lab · 从零练习 C 语言

一个面向 C 语言初学者的中文交互式学习网站。当前版本聚焦最基础的六个主题：认识 C 程序、变量、输出、输入、`if` 判断和 `for` 循环。

## 运行

无需安装依赖，也不需要账号或后端服务。直接用浏览器打开 `index.html` 即可。也可以在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 已有功能

- 六节短课，每节包含概念说明、代码示例和选择题。
- 课程导航、学习进度条、完成状态和代码复制。
- 学习进度保存在当前浏览器的 `localStorage`；重置按钮可清除本地进度。
- 手机和电脑屏幕均可使用。
- 纯静态页面，没有登录、后端、第三方脚本或数据上传。

## 文件

- `index.html`：页面、样式和交互逻辑。
- `SECURITY.md`：当前版本的安全检查与维护要求。
- `.gitignore`：忽略本地编辑器、系统和临时文件。
